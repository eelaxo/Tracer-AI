The AI in this prototype

risk = sigmoid( −2.2 + 2.2·victim_inflow + 1.6·speed + 1.2·fan_out + 2.0·mixer + 1.0·bridge + 1.1·new_wallet + 0.8·odd_splits − 2.5·exchange_pattern )

Weights are set by hand here so every step can be explained. In production the same signals train a model (XGBoost, then a graph neural network) on labelled cases, and deposit addresses that sweep into one hot wallet are clustered to name the exchange.
